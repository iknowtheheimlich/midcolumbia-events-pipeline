# Attempt_22_Harvest_Infrastructure

## Objective

Create a reproducible harvest layer that can refresh raw source fixtures, regenerate normalized fixtures, and run the existing pipeline smoke check from one command.

## Command

```powershell
python -m tools.harvest_all
```

Offline normalized-regeneration mode:

```powershell
python -m tools.harvest_all --skip-fetch
```

Single-source mode:

```powershell
python -m tools.harvest_all --source VisitTriCities
```

Legacy bridge regeneration:

```powershell
python -m tools.harvest_all --source LegacyUnifiedCSV --legacy-input path\to\unified_events.csv
```

## Boundaries

Attempt_22 is infrastructure only.

No intentional changes are made to:

- canonical event schema
- publisher
- venue resolver
- deduplication
- recurrence classification

## Fixture Contract

Each active source has two fixture layers:

1. raw fixture generated by the source harvester
2. normalized fixture generated by the existing adapter parser

Normalized fixtures remain the input to the shared pipeline spine.

## Current Harvesters

- `VisitTriCities` — Algolia multi-query payload
- `RichlandLibrary` — LibCal monthly HTML fragments
- `MidColumbiaLibraries` — public events listing HTML
- `TriCityVibe` — listing HTML, guarded so stale checkouts fail loudly if the adapter is missing
- `LegacyUnifiedCSV` — migration bridge; regenerates only when `--legacy-input` is supplied

## Verification

Run after harvest:

```powershell
python -m tools.harvest_all --skip-fetch
python -m pytest
```

The harvest command performs a final `run_pipeline(..., deduplicate=True)` smoke check unless `--skip-pipeline-smoke` is supplied.
