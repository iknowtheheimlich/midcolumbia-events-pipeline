## Included Capabilities

- multi-source event adapters and shared normalization contract
- canonical event schema and source attribution
- venue and organizer registries
- conservative deduplication and occurrence resolution
- explainable category classification with evidence precedence
- venue and organizer category priors
- durable classified-event history and corpus snapshots
- venue-intelligence discovery and knowledge-drift reporting
- human classification-review batch export/import
- idempotent review ledger
- review-state reconciliation
- backlog aging, SLA, throughput, and capacity monitoring
- typed review-operations configuration
- consolidated review metrics
- unified weekly operational dashboard
- Reddit publisher and editorial output contracts

## Compatibility

The release candidate preserves established public function names and legacy weekly-finalizer keyword arguments where practical. Configuration files and explicit overrides follow the documented precedence contract.

## Known Limitations

1. The repository does not yet contain a dependency manifest such as `requirements.txt` or `pyproject.toml`.
2. Final v1.0 installation must be verified from a clean checkout after that manifest is added.
3. Venue and organizer intelligence depend on accumulated classified history; small corpora correctly produce insufficient-evidence results rather than promotions.
4. Analytical reports are non-blocking during weekly finalization, but any reported failure must be investigated before release or publication.
5. Dashboard status summarizes operational state; it does not replace inspection of publisher-ready event output.

## Promotion Criteria for v1.0.0

- complete at least one real weekly cycle on the release candidate
- maintain a green full regression suite
- confirm review-ledger idempotency and backlog consistency
- add and verify a dependency manifest
- verify installation and canonical commands from a clean checkout
- resolve or explicitly accept all dashboard warnings
- update final release notes and tag the verified merge commit
